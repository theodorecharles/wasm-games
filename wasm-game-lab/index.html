Double-click a runnable game to open its canonical family container in a new tab. A green dot means the local endpoint answered; a red dot means it is unavailable. A gray × marks a development entry whose project intentionally publishes no runtime image yet.

Wolfenstein: Enemy Territory is Live. Every other shortcut is Still in development. Hover over a shortcut for its family, variant, and status.

Each runnable game container keeps required files in its persistent local /data mount. Browser caching and first-run setup stay inside the shared framework.
