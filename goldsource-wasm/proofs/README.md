# GoldSrc campaign browser proof

Current report: `campaign-intros.json`

SHA-256: `21343feafb4dead5f6328f8a0a07daec94949b2bc9b3e8b330013e354836cfaa`

`campaign-intros.json` is generated by a real Chrome DevTools Protocol run of
the three single-player campaigns. The test starts each canonical intro map,
uses a fixed engine frame time to accelerate only the passage of game time,
polls Xash's authoritative `status` output, and requires the exact non-looping
map sequence to end in native `gameplay` state with no fatal engine errors.

Run it while the GoldSrc site is served with validated owner data:

```sh
node goldsource-wasm/scripts/test-campaign-intros-browser.mjs \
  --output goldsource-wasm/proofs/campaign-intros.json
```

The expected sequences are:

- Half-Life: `c0a0 → c0a0a → c0a0b → c0a0c → c0a0d → c0a0e`
- Blue Shift: `ba_tram1 → ba_tram2 → ba_tram3`
- Opposing Force: `of0a0 → of1a1`
