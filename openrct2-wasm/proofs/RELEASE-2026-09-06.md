## Rerun and rollback

From the repository root:

```sh
node openrct2-wasm/games/openrct2/scripts/test-release-package.mjs --installed
node openrct2-wasm/games/openrct2/scripts/test-release-evidence.mjs
```

The pre-deployment mode `--record-before` is write-once and intentionally
requires the old live image. It must not be used to replace the baseline after
deployment. Historical one-change checkpoint verifiers keep their own hashes.

Rollback image `e00af4e3735efae516493824168208c57f1c41b47d43a679beb777957d942493`
is retained as `local/openrct2-wasm:live-baseline-20260906`. To roll back, restore
the old OpenRCT2 image contract/framework pin, retag that image to the canonical
tag, and point only OpenRCT2's data bind back at the original directory before
recreating that service with `--no-deps`. Preserve both directories: later
imports into the new directory must not be discarded. Browser saves remain
origin-specific; no hidden browser-storage read, export or migration was used.

Listening/audio quality, broader cache upgrades, extended park operation and
the remaining portfolio issues stay open. Blood's crash remains user-deferred.
