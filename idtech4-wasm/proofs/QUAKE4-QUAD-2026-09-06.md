## Repair

The [earlier intro investigation](QUAKE4-INTRO-2026-09-06.md) identified the exact
gray-producing draw: an immediate-mode brightness quad read a preceding model
VBO instead of its four CPU vertices. The canonical OpenQ4 patch now installs
`tools/build/emscripten_immediate_buffer.mjs` through the legacy-GL transform.
It scopes SDK `glEnd` to the CPU stream, restores logical and physical application
bindings in `finally`, and invalidates the prepared-buffer cache. Meson declares
the helper as an actual link dependency; the regenerated Ninja graph contains it.

The separate `RB_InteractionRescueActive` policy now recognizes that WebGL uses
validated GLSL ES, not desktop ARB assembly. Missing deliberately unuploaded ARB
programs no longer impose an automatic 0.2 brightness floor. The fatal GLSL
readiness check, desktop shader selection, explicit interaction-disable rescue,
and clamped user `r_forceAmbient` setting are preserved.
